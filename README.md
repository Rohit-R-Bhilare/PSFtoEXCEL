## 📌 Overview

**PSF to Excel Converter** is a full-stack web application designed to simplify the process of converting structured `.psf` files into Excel spreadsheets.

The application provides a simple workflow:

```text
📂 Upload PSF
      ↓
⚙️ Parse PSF
      ↓
📊 Preview Data
      ↓
🔎 Search / Filter
      ↓
📥 Export Excel
